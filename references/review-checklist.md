# 交付前自检清单

宿主没有 shell 能力时，按这份清单人工逐条核对，替代 `validate.mjs`。

---

## A. 文件级（4 条，任一不过 = 不可交付）

- [ ] 是**单个** `.html` 文件，没有额外 `.css` / `.js` / 图片文件
- [ ] 全文搜索 `http://` `https://`，只剩注释或空 —— **零外部请求**
- [ ] 双击用浏览器打开能正常渲染，不需要起服务器
- [ ] 文件大小 < 400KB

---

## B. 路由级（3 条）

- [ ] 至少 2 个路由，且能用侧边栏/nav 互相到达
- [ ] 浏览器**后退**能回到上一页（`hashchange` 生效）
- [ ] 直接粘贴 `#/xxx/:id` 形式的深链能直接打开对应页

---

## C. 追溯级（4 条）

- [ ] 每个按钮/链接/输入框都有 `data-req`
- [ ] 原型内嵌了 `#req-map`，且和功能清单快照逐条一致
- [ ] 所有 `data-req` 值都能在 `#req-map` 里找到同 id 的 `F-xx`
- [ ] 评审模式能打开，P0 无红项，P2 缺失有黄色标注

---

## D. 状态级（3 条）

- [ ] 至少一页实现了空态（`?state=empty`）
- [ ] 至少一页实现了错误态（`?state=error`）
- [ ] 有数据的页面首次进入有加载态（骨架屏或 loading）

---

## E. 视觉级（6 条）

- [ ] 颜色全部来自 `theme.css` 的 token，没有临场写的 hex
- [ ] 间距是 4 的倍数（4/8/12/16/24/32）
- [ ] 圆角统一（按钮 8-10px，卡片 12-16px，弹窗 16-20px）
- [ ] 一屏不超过 3 个视觉层级，有明确焦点
- [ ] 正文对比度 ≥ 4.5:1
- [ ] 侧边栏导航当前项高亮，且和路由一致

---

## F. 内容级（4 条）

- [ ] 没有 `lorem ipsum`、`TODO`、`xxx`、`张三`、`test123`
- [ ] 假数据有真实业务语义（订单号 `TK-20261029-001`、金额 `1,280.00`）
- [ ] 空态有引导文案 + 一个动作按钮，不是空白
- [ ] 错误态说明原因 + 给重试路径，不是只写"出错了"

---

## G. 交互级（4 条）

- [ ] 抽屉/弹窗能用 ESC 关闭
- [ ] 点遮罩能关闭抽屉/弹窗
- [ ] 表单提交失败时错误显示在字段下方，没有 `alert`
- [ ] Toast 3 秒自动消失，不会叠一片

---

## 收尾

全部打勾后再走交付说明模板。**有任一项没勾，要么修，要么在交付说明里明确写出来"未实现 X，原因 Y"**——不许假装做过。
